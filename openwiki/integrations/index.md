# Files

- [AI assistance](ai-assistance.md) - How Examinus uses OpenAI, Claude and Gemini — per-organization keys stored encrypted, question drafting into a quiz part or the question bank through the kinds' draft shapes, score and feedback suggestions for essays, the student coach report with its rule-based fallback — and the permissions, rate limits and visibility rules around it.

- [Google sign-in and Classroom import](google-classroom.md) - What Google needs in the Cloud Console and on the API, how Google OAuth is used for sign-in, sign-up and linking a teacher's account with read-only Classroom scopes, how courses are imported as classes and rosters synced, token refresh and failure messages, and how imported roster entries are later claimed.
- [MCP server](mcp-server.md) - apps/mcp, an MCP server over stdio that lets an AI client act as a signed-in teacher through the RPC API — how it signs in and re-authenticates, how tool inputs are validated, the tools for creating quizzes and questions, analysing a session's questions and answers, and reporting on classes and students, and how its numbers mirror the web pages.
